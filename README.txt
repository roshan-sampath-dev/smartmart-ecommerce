# SmartMart HTML Pages

This package contains the HTML page layer for the SmartMart ITE 1713 project.

## Included pages
- `index.html`
- `products.html`
- `categories.html`
- `product-details.html`
- `wishlist.html`
- `cart.html`
- `checkout.html`
- `order-success.html`
- `my-orders.html`
- `login.html`
- `register.html`
- `about.html`
- `contact.html`
- `admin-dashboard.html`
- `admin-products.html`
- `admin-categories.html`
- `admin-inventory.html`
- `admin-orders.html`

## Important
- These are complete HTML page structures, not a complete working e-commerce application.
- CSS styling and JavaScript behavior are intentionally separate and must be implemented in `css/style.css` and `js/app.js`.
- Product images are placeholders. Add matching files under `assets/images/`.
- Forms, cart, filters, reviews, authentication, admin actions and order handling need JavaScript and/or a backend.
- Login and registration are demo UI only. Do not enter real passwords or payment information.
- The VAT rate shown in the cart is the educational project assumption of 18%, not a statement of the current legal VAT rate.
